# Usage
To use Cloner, navigate to any of the below supported 'grouping' screens in your control panel. You should see a small `+` icon. Click this to open up a prompt window to enter the new name for your group.

Supports cloning:
- Asset Transforms
- Category Groups
- Entry Types
- Filesystems
- Global Sets
- Sections
- Tag Groups
- User Groups
- Volumes

For example, clone a category group when a new content area needs the same field layout as an existing one. Open Settings → Categories, use the `+` action beside the source group and give the copy a distinct name. Open the copied group's settings and review its handle and field layout before using it.

Cloner works with the selected configuration object. Do not treat it as a content export or assume that a copied group also contains copies of its elements. Check the resulting group before editors begin creating content in it.
