Cloner turns a well-configured Craft structure into a reusable starting point. Duplicate sections, entry types, groups, volumes, filesystems, transforms, and other project settings without rebuilding them by hand.

Start from an existing configuration and let Cloner copy its settings, then change only the details that need to differ.

## Features

- Duplicate sections and entry types without copying their content.
- Create a new category or tag group from an existing group's setup.
- Copy a user group's permissions as the basis for a new role.
- Copy volumes and filesystems before tailoring the destination.
- Repeat image-transform settings without re-entering every dimension and mode.
- Create a new global set from an existing one.
- Duplicate an existing site's settings before tailoring its name, handle, language, and URL.
