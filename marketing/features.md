<!-- feature-intro -->
Cloner turns a well-configured Craft structure into a reusable starting point. Duplicate sections, entry types, groups, volumes, filesystems, transforms, and other project settings without rebuilding them by hand.
<!-- feature-intro-end -->

<!-- feature-section -->
## Skip the repetitive setup

The second section with a familiar shape should not take as long as the first. Start from an existing configuration, choose a new name and handle, and let Cloner copy the settings — including substantial field layouts — ready for the details that actually need to differ.

<!-- feature-section-end -->

<!-- feature-grid -->
- :icon[layout-list] **Sections and entry types** Duplicate established content structures and their configuration.
- :icon[category] **Category and tag groups** Create a new taxonomy from an existing group’s setup.
- :icon[users-group] **User groups** Reuse a group as the basis for a new permissions workflow.
- :icon[folder] **Volumes and filesystems** Copy asset storage configurations before tailoring the destination.
- :icon[photo] **Asset transforms** Repeat image-transform settings without re-entering every dimension and mode.
- :icon[world] **Global sets** Create a new global-set configuration from a proven starting point.
- :icon[world-www] **Sites** Duplicate an existing site’s language, base URL and other settings as a new starting point.
<!-- feature-grid-end -->

<!-- feature-section -->
## Yours to change

Cloner does not create a parallel configuration system. The duplicate is a normal Craft configuration item, ready to adjust through the usual settings screens; it handles the repetitive setup and then gets out of the way.
<!-- feature-section-end -->
